misaka108432023-01-292023-02-24

芳文幻想曲是一个 2D RPG 轻百日常类游戏，使用 unity 制作，以芳文社漫画为主的一个同人游戏

芳文ファンタジアは、芳文社の漫画を原作とし、unity で制作された 2D RPG です。

此仓库使用Unity 2021.3.13f1制作

简介

芳文狂想曲（不是 kirara！）正式开始制作啦！

因为是 2DRPG，所以我们希望有会美术的小伙伴加入我们制作团队 qwq

这个游戏是主打将芳文社出版的萌系漫画改编成游戏，不同于 kirara 狂想曲，芳文狂想曲是一个类开放，2D，RPG 游戏，预计你可以在此游戏中跟其他人贴贴，也可以在 slow loop 中的海边喝着智乃泡的咖啡等等 www

或者你也可以体验在本溪湖旁跟芝麻凛露营，或者跟海果一起造火箭，只要漫画中出现的东西，我们都会尽力去完成！

项目相关

此项目使用 Visual Scripting来可视化编程

贴图分辨率暂时设置为 32x32（可能会降到 16x16）

此项目开启了 URP(通用渲染管线)，所以可能会导致一些并不属于 URP的预制件导入后出现显示问题，还请自己修改

插件环境

为了能让开发顺利展开，并且尽可能统一代码规范，还请额外安装以下插件！

VsCode

  • Unity Dev Pack - Visual Studio Marketplace（建议安装）
  • 自行准备代码格式化插件

Visual Studio

  • CodeMaid VS2022 - Visual Studio Marketplace
  • Auto Save File - Visual Studio Marketplace（建议安装）
