前言

因为网站/个人需要一些 api，所以编写了一些常用的+反代的 api

为了防止自己忘记所以就出篇文章备份一下

1.随机动漫壁纸 API

1.直接访问

您可以直接访问 此链接 即可获取图片(直接返回图片)

链接: https://action.sakurakoyi.top:10010/api/acg.php

返回(图片已缩小)：

2.通过 json 访问

请求方式：

GET https://action.sakurakoyi.top/api/acg.php?json=1

返回数据：

3.附加参数

此 API 可以附加 folder/num/picnum参数

1.其中，如果您想指定哪个文件夹图片，您可以使用以下 folder参数

参数表示
misakamisaka10843 的 pixiv 收藏
qwq我永远喜欢空银子的收集图片
qwq2.0我永远喜欢空银子的收集图片
随机图片浅笙-梦羽的收集图片

folder参数使用说明
普通访问：
https://action.sakurakoyi.top/api/acg.php?folder={参数}

json 访问：
https://action.sakurakoyi.top/api/acg.php?folder={参数}&json=1

例如：
https://action.sakurakoyi.top/api/acg.php?folder=misaka即可访问 misaka10843的pixiv收藏

返回(图片已缩小)：

2.其中，您想输出多个图片，您可以这样使用 num参数

取 1-50之间的自然数填入 num参数即可

注意！此参数必须要通过json 访问才可以运行！

num参数使用说明

json 访问：

https://action.sakurakoyi.top/api/acg.php?num={1-50之间的自然数}&json=1

例如：

https://action.sakurakoyi.top/api/acg.php?num=10&json=1

返回：

3.其中，您想获取 API 中图片数量，您可以这样使用 picnum参数

直接访问此链接即可~
https://action.sakurakoyi.top/api/acg.php?picnum=1

注意！此参数必须只能严格按照上面链接访问才可以运行！

picnum参数使用说明

普通访问：
https://action.sakurakoyi.top/api/acg.php?picnum=1
返回：
现有图片数量：738

2.通过 json 访问

请求方式:

GET https://action.sakurakoyi.top/api/ani-text.php?json=1

返回数据：

1.通过 json 访问

请求方式：

GET https://action.sakurakoyi.top/bilibili.php?aid={av号}

返回数据：

注意！因为著名的跨域问题，您似乎并不能在加速器的情况下打开此页面！

5.TokyoMX 当日节目表 API

此 API 是获取日本电视台-TokyoMX1 台的当日节目表(其中喵帕斯动画的 TokyoMX 直播的节目单就是使用的此 API)

1.直接访问

链接：

https://action.sakurakoyi.top/api/tokyoMX

2.json 访问

请求方式：

GET https://action.sakurakoyi.top/api/tokyoMX?json=1

返回数据：

6.json 跨域支持 API

此 API 是将一些无法跨域使用的 json 通过 API 实现跨域请求
（不是返回 jsonp，而是 json）

1.直接访问

链接：

https://action.sakurakoyi.top/api/json?url={链接}
